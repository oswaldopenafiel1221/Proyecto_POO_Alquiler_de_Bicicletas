# Proyecto POO: Sistema de Alquiler de Bicicletas

## Descripción:
El sistema permite registrar clientes, visualizar el inventario disponible, procesar alquileres y procesar devoluciones. El código fue estructurado aplicando lo aprendido en POO, temas como encapsulamiento, herencia, polimorfismo, interfaces y el uso de colecciones (ArrayList).

## Tecnologías usadas:
* Lenguaje de Programación:Java
* Entorno de Desarrollo Integrado (IDE): Apache NetBeans
* Control de Versiones: Git y GitHub

## Instrucciones de ejecución
Para probar y ejecutar este proyecto puede seguir estos pasos:
1. En la página principal de este repositorio, descargar el archivo .zip .
2. Descomprime el archivo .zip.
3. Abrirlo con el Apache NetBeans.
4. En el panel de proyectos, despliega la carpeta de paquetes y abrir el paquete Main.
6.  compilar e interactúar con el menú principal digitando los números correspondientes a cada opción en la consola.
